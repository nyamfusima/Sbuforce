You are a senior UI/UX designer, frontend engineer and conversion-focused web designer.

You are working on an existing Lovable-generated codebase for a SECURITY SERVICES COMPANY.

Your job is NOT to simply polish the existing Lovable design.

You must transform the existing codebase into a professional, credible, high-end security company website that feels intentionally designed for THIS specific company.

==================================================

The website should communicate:

SECURITY
TRUST
AUTHORITY
RELIABILITY

DISCIPLINE
RESPONSIVENESS

It should look like a company that a business, property owner, estate, commercial client or private client would trust with their security.

The design should feel:

- Premium
- Serious
- Modern
- Structured
- Confident
- Professional
- Established
- Human

Think:

"professional security firm"

NOT:

"generic security website"

==================================================
PHASE 5 — VISUAL DESIGN
==================================================

Create a strong visual system.

Use the client's existing branding wherever available.

If the document contains brand colours, use those.

If there is no sufficiently defined palette, create a restrained professional palette.

Prefer:

- Deep dark tones
- Strong neutral backgrounds
- One controlled accent colour
- High contrast
- Clean white/neutral space

Do not use five or six unrelated colours.

The interface should feel cohesive.

==================================================
TYPOGRAPHY
==================================================

Typography must feel intentional.

Use:

- Strong display typography for major headings
- Highly readable body typography
- Clear hierarchy
- Proper line height
- Controlled font weights

Do not make every heading enormous.

Avoid:

"WE KEEP YOU SAFE"

"YOUR SECURITY IS OUR PRIORITY"

"PROTECT WHAT MATTERS"

unless the client's actual content supports such wording.

Do not generate generic security slogans just to fill space.

==================================================
LAYOUT
==================================================

Use strong editorial layouts.

Avoid making every section:

[icon]
[heading]
[text]
[button]

Instead vary layouts:

- Split-screen sections
- Asymmetric grids
- Large photography
- Structured content blocks
- Full-width sections
- Overlapping elements where appropriate
- Strong whitespace
- Clear content hierarchy
- Alternating visual/text layouts

Every section should have a reason to exist.

==================================================
HERO SECTION
==================================================

The hero is one of the most important sections.

It should immediately communicate:

1. Who the company is
2. What it does
3. Who it serves
4. What the visitor should do next

Use strong professional imagery.

Do not overload the hero with:

- Multiple CTAs
- Floating cards
- Statistics
- Random badges
- Decorative elements

Primary CTA should be based on the client's actual business goal.

Possible CTA:

"Request a Quote"

Secondary CTA:

"Explore Our Services"

Only use these if appropriate to the client's content.

==================================================
SERVICES
==================================================

Services must be presented clearly.

Do not create generic cards simply because a design template expects them.

Use the services listed in the client's document.

Each service should have:

- Clear name
- Concise description
- Relevant visual treatment
- Optional supporting link/action

Prioritise the services that matter most commercially.

==================================================
TRUST & CREDIBILITY
==================================================

Security websites require trust.

Use real information from the client's document.

Where supported, highlight:

- Certifications
- Registrations
- Professional qualifications
- Experience
- Service areas
- Company values
- Leadership
- Operational capabilities

Do not invent credibility indicators.

==================================================
IMAGERY
==================================================

Photography must look intentional.

Use imagery related to the actual services.

Avoid random images of:

- Generic men in suits
- Random security guards
- Generic CCTV cameras
- Police cars
- Guns
- Generic skyscrapers

unless they directly relate to the company's services.

Prefer:

- Professional security personnel
- Commercial security environments
- Residential security environments
- Access control
- Monitoring
- Patrol environments
- Professional team imagery
- Real company imagery supplied by the client

Do not reuse the same image repeatedly unless there is a strong design reason.

==================================================
NAVIGATION
==================================================

Create a clean, professional navigation.

Prioritise the most important pages/sections.

Do not overload the navbar.

The main CTA should stand out without looking like a glowing marketing button.

Navigation must work perfectly on mobile.

==================================================
PAGES
==================================================

Determine whether the existing project should use:

- A strong single-page experience
- Multiple pages
- Or a hybrid structure

Important business information that deserves a dedicated page should not necessarily be forced into one long homepage.

At minimum consider:

Home
About
Services
Contact

Only create additional pages when the client's content supports them.

==================================================
CONTACT & CONVERSION
==================================================

The website should make contacting the company extremely easy.

Use:

- Phone
- Email
- WhatsApp
- Contact form
- Quote/request CTA

where those details exist in the client document.

Make the contact experience feel professional.

Do not make users search for the contact information.

==================================================
WHATSAPP
==================================================

If the client has a WhatsApp number:

Create a proper WhatsApp CTA.

It should open the correct WhatsApp number.

Do not use a fake number.

Use the correct international format for the WhatsApp link.

==================================================
FORMS
==================================================

Forms should be simple.

Only request information that is actually necessary.

Example:

Name
Company
Phone
Email
Service Required
Message

Do not create unnecessarily long forms.

==================================================
ANIMATION
==================================================

Animations should be subtle and purposeful.

Use:

- Smooth section reveals
- Small hover transitions
- Image transitions
- Navigation transitions
- Button micro-interactions

Avoid:

- Constant movement
- Excessive parallax
- Bouncing elements
- Spinning icons
- Attention-grabbing animations
- Animation on every element

The website should feel premium, not animated for the sake of being animated.

ACCESSIBILITY

- Proper button/link semantics

SEO

- Unique page titles
- Meta descriptions
- Correct H1
- Logical H2/H3 structure
- Descriptive URLs
- Image alt text
- Open Graph metadata
- Favicon

SEO content must remain natural and professional.

==================================================
PERFORMANCE
==================================================

Optimise for performance.

Avoid:

- Huge unoptimised images
- Unnecessary dependencies
- Excessive JavaScript
- Heavy animation libraries when CSS is sufficient
- Duplicate components
- Unused assets

Use modern image optimisation where supported.

CODE QUALITY

Write production-quality code.

Requirements:

- Clear component naming
- Clean folder structure
- No duplicated code unnecessarily
- No hardcoded secrets

- No unnecessary dependencies

Services are grouped (`serviceGroups`: Guarding & Armed Response as primary, Monitoring & Access Control as secondary) rather than one flat card grid — see RULES.md §6.
